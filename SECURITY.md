# Security and Ethical Use Policy

## Ethical Scope and Legal Disclaimer

ARGUS is engineered exclusively for defensive auditing, authorized administrative monitoring, and security research on networks where the operator possesses explicit written consent from the network owner.

Running automated discovery sweeps, port inspections, or deep service enumerations against subnets without authorization violates network acceptable use policies and statutory cybercrime legislation. The authors assume no liability for misuse, unauthorized operations, or operational disruptions caused by the execution of this platform.

## Supported Versions

Security fixes and defensive updates apply to the active development branch:

* Version 2.0 receives continuous updates and fixes
* Legacy prototypes receive no active maintenance

## Reporting Vulnerabilities

If you identify a security flaw or an exploitable logic error within the ARGUS ingestion or inspection engine:

1. Do not open a public issue on GitHub.
2. Formulate a proof of concept detailing reproduction steps and potential impact.
3. Submit your advisory directly to the project maintainer via repository contact channels.

Maintainers evaluate submitted issues within forty eight hours and will coordinate a responsible release date before public disclosure.
